🌐 Sobre el proyecto

Game Archive es un sitio web pensado para recopilar los precios de videojuegos publicados en distintas tiendas online y permitir que los usuarios los comparen en un mismo lugar.

La propuesta busca facilitar la búsqueda de ofertas y ayudar a identificar dónde se encuentra el precio más bajo para cada videojuego.

🎯 Objetivo del sitio

El objetivo principal es desarrollar un sitio web que reúna precios de videojuegos de diferentes tiendas, ofreciendo una forma sencilla de comparar sus valores y encontrar la alternativa más económica.
